# Governance Boundaries: 治理边界声明

**`agent-governance` 知道自己能治理什么，不能治理什么。**

这不是一个"万能治理框架"。我们明确声明治理层的**能力边界**，确保用户不会误用。

---

## 治理能力矩阵

### 能治理 ✅

| 场景类别 | 特征 | 治理方式 | 涉及的模块 |
|----------|------|----------|-----------|
| **确定性任务** | 输入/输出空间有限、奖励可量化 | 元认知周期 → 策略A/B调节 | MCL + FPD |
| **可测量反馈** | 每次决策有明确的成功/失败信号 | 奖励追踪 → 失败模式检测 | MCL.evaluate() |
| **有限状态空间** | 任务的状态转移可枚举 | 策略评估 + 收敛检测 | FPD + MCL |
| **自指安全风险** | Agent声称"我是安全的"或"我从不犯错" | 哥德尔边界检测 → 外部验证路由 | GB + SelfCheck |
| **Sim-to-Real Gap** | 仿真与实机之间存在可测量的差距 | 差距量化 + 参数校准 + 漂移检测 | DTC |
| **已知漏洞** | 系统架构中已经识别了逻辑矛盾 | 静态矛盾模板 + 动态检测 | SelfCheck |
| **可审计决策** | 决策路径可追溯、可回放 | 日志记录 + get_dashboard() | 全部模块 |

### 不能治理 ❌

| 场景类别 | 为什么不能 | 会发生什么 | 建议 |
|----------|-----------|-----------|------|
| **开放性创意任务** | 没有明确的"正确/错误"标准 | MCL 无法评估策略效果 → 循环退化 | 使用人类反馈作为替代奖励 |
| **不可测量的反馈** | 决策结果无法用数值表达 | FPD 无法计算 convergence delta | 定义代理指标 |
| **无限状态空间** | 状态太多，无法枚举和评估 | MCL 的 evaluate() 不触发 | 限制到局部状态子空间 |
| **实时硬约束** | 治理检查引入延迟（ms级） | 在 <10ms 决策场景中不可用 | 使用前置编译规则而非运行时检查 |
| **政治/伦理模糊决策** | 没有客观的"正确"答案 | GB 和 SelfCheck 无法判定 | **必须人类介入** |
| **对抗性攻击** | 刻意设计的恶意输入旨在绕过治理层 | 危险模式匹配可能被绕过 | 建议在治理层外加防火墙 |

### 需要人类介入 ⚠️

| 场景 | 为什么需要人类 | 治理层的行为 |
|------|---------------|-------------|
| **不可逆操作** | 删除数据、格式化、物理操作 | 自动路由到 EXTERNALIZE → 要求人类确认 |
| **重大安全影响** | 涉及生命安全的决策 | 强制 EXTERNALIZE → 拒绝自动执行 |
| **信任根变更** | 修改系统的基本公理 | SelfCheck 检测到 → 标记 CRITICAL → 阻止 |
| **初次部署** | 新环境首次上线 | DTC 标记 UNCALIBRATED → 要求人工校准 |
| **漂移检测** | 参数持续偏离（可能硬件故障） | DTC 标记 DRIFTING → 建议人工检查 |

## 治理层的自我声明

`agent-governance` 本身不声称：

| 不声称 | 原因 |
|--------|------|
| **"本框架保证 Agent 安全"** | 哥德尔不完备定理：任何足够强大的自指系统都无法自证完备 |
| **"本框架可以检测所有不安全行为"** | 危险模式匹配基于已知模式，无法覆盖所有未知危险 |
| **"本框架替代人类判断"** | 治理层是辅助工具，不是替代决策者 |
| **"本框架适用于所有 Agent"** | 只在"能治理"矩阵范围内有效 |

---

## 治理效果预期

| 场景 | 预期效果 | 置信度 |
|------|----------|:------:|
| 检测自指不安全声明 | >80% 召回率 | 高 |
| 检测假收敛 | >90% 精确率 | 高 |
| 阻止已知危险模式 | ~100% | 极高 |
| 识别新的危险行为 | 不确定 | 低 |
| Sim-to-Real 差距量化 | 误差 <20% | 中 |
| 策略优化的全局最优性 | 无法保证 | — |

---

## 总结

```
治理边界 = 能治理的领域 ∩ 有反馈的领域 ∩ 可审计的领域
治理层不是防火墙、不是保险、不是替代人类判断。
```
